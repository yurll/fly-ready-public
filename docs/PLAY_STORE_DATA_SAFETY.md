# Fly Ready Play Store Data Safety

## Current Intended Data Safety Notes

* No account is required.
* No airline credentials are collected.
* Fly Ready does not collect, transmit, or share user data with the developer or a Fly Ready backend.
* Trips, booking references, reminders, checklist state, and imported documents are stored locally on device.
* Notification permission is used for local reminders.
* Imported documents are selected by the user and copied to app-private storage.
* User can delete all local data from Settings.
* Android system backup is disabled and backup rules exclude stored travel data.
* This draft must be reviewed before Play Store submission.
